# ERD Studio Downloads

ERD Studioの試用版バイナリ配布用リポジトリです。ソースコードはこのリポジトリには含まれません。

## Download

最新版は[Releases](https://github.com/chidai/erd-studio-dist/releases)からダウンロードしてください。

- macOS: Apple Silicon（M1以降）またはIntel x64、macOS 12以降、PKG形式
- Windows: x64、portable ZIP形式。展開後に`ERD Studio.exe`を実行

## Alpha version notice

試用中のalpha版です。重要なモデルはバックアップを取ってから使用してください。現在の配布物はコード署名されていないため、macOS GatekeeperまたはWindows SmartScreenの警告が表示される場合があります。

macOSでブロックされた場合は、PKGを一度開いた後、「システム設定」→「プライバシーとセキュリティ」に表示される確認から許可してください。

Macは機種に合うファイルを選んでください。M1以降は`mac-arm64.pkg`、Intel Macは`mac-x64.pkg`です。
